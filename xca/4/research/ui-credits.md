# UI icon credits

Art style: chunky white silhouette icons on rounded dark-purple panels with pumpkin-orange outlines.
The icons are tinted in code, so one white PNG serves every colour state.
Each PNG is a 256 px render of the source SVG, recoloured to white. Shape is unchanged.
